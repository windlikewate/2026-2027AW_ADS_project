最短路径问题是组合优化领域中最基础的问题之一，既有许多直接应用，也常作为其他组合优化算法的子程序。自 20 世纪 50 年代以来，人们一直在研究这类问题的算法，如今它仍是一个活跃的研究领域。

本项目要求使用 Dijkstra 算法计算最短路径。实现应基于最小优先队列，例如斐波那契堆。项目目标是为 Dijkstra 算法寻找最佳数据结构。

## 任务要求

1. 使用至少两种不同的堆结构实现该算法，其中必须包含斐波那契堆。
2. 使用美国道路网络进行评估。数据集可从[第九届 DIMACS 实现挑战赛](http://www.dis.uniroma1.it/challenge9/download.shtml)下载。
   - **注意：**报告中只需列出这些测试数据集的下载链接，不要上传数据集。
3. 至少使用 1,000 对查询来评估不同实现的运行时间。

## 评分标准

- 撰写分析与说明（3 分）。
